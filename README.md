# IS 492 Assignment 2: n8n Research Workflow

This assignment introduces workflow automation with n8n.

Students will build an automated workflow that:

- retrieves research papers from arXiv;
- parses and transforms XML data;
- summarizes a paper abstract using a Groq language model;
- sends the result through Gmail;
- implements at least two additional workflow features.
